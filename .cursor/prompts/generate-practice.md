Create the practice roadmap entry for **<PATTERN>** in
`part-5-practice-roadmap/`.

Steps:

1. Pull candidate questions from `QUESTION_BANK.md` for this pattern (add more
   there first if the pool is thin)
2. Select 5-8 questions that together cover the core variations of the
   pattern, ordered from easiest to hardest
3. For each question, write one sentence on _why it matters_ — what specific
   variation or edge case it teaches that the others don't
4. Do not just list problems — the point is that solving these 5-8 is
   equivalent in value to solving 20+ near-duplicates

Append the entry to `part-5-practice-roadmap/` using this format:

```markdown

2. **<Question>** — <why it matters>
   ...
```
