# Family 7 — Practice Shortlist

Aim: **5–8 drills per pattern**. One line = why it matters for recognition.

## Stack

1. **Valid Parentheses** — Matching baseline; last-in closes first.
2. **Min Stack** — Extra stack for running minima.
3. **Evaluate RPN** — Operand stack evaluation.
4. **Decode String** — Nested counts/strings on a stack.
5. **Basic Calculator** — Signs + stack frames for parentheses.
6. **Simplify Path** — Path segments push/pop like folders.

## Queue

1. **Implement Queue using Stacks** — Two-stack transfer (average cheap).
2. **Moving Average from Data Stream** — FIFO window sum.
3. **Design Circular Queue** — Mod indices; capacity edges.
4. **Number of Recent Calls** — Drop expired items from the front.
5. **Design Hit Counter** — Same FIFO purge idea at second grain.
6. **Sliding Window Maximum** — Dual-home: deque monotonic queue (also Mono Stack).

## Heap / Priority Queue

1. **Kth Largest Element** — Size-K min-heap selection.
2. **K Closest Points** — Distance heap / size-K.
3. **Top K Frequent** — Count (map) then select (heap).
4. **Task Scheduler** — Frequency priorities / cooldown.
5. **Merge k Sorted Lists** — K-way heap merge.
6. **Find Median from Data Stream** — Two heaps balance.

## Monotonic Stack

1. **Next Greater Element I** — Map answers via mono stack.
2. **Daily Temperatures** — Distances via decreasing indices.
3. **Online Stock Span** — Span widths while stack shrinks.
4. **Next Greater Element II** — Circular 2n pass.
5. **Largest Rectangle in Histogram** — Hard classic widths via mono stack.
6. **Maximal Rectangle** — Histogram heights per row.

## Trie

1. **Implement Trie** — Children + `is_end` muscle memory.
2. **Design Add and Search Words** — Wildcard DFS on trie.
3. **Replace Words** — Shortest root prefix in dictionary.
4. **Word Search II** — Trie of words + board backtracking.
5. **Design Search Autocomplete System** — Hot prefixes under shared paths.
6. **Maximum XOR of Two Numbers** — Bit trie alternative flavor.
