## Study Protocol

1. Name the pattern **before** coding (Part 3 stems help).
2. Solve without looking at Part 2 templates; then compare.
3. For dual-home problems, note which pattern owned the hard part.
4. After each family, redo that family's stems from
   [`../part-3-pattern-recognition/recognition-stems.md`](../part-3-pattern-recognition/recognition-stems.md).
