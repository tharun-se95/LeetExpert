# Family 2 — Practice Shortlist

## Two Pointers

1. **Valid Palindrome** — Ends walk inward; baseline compare.
2. **Remove Duplicates from Sorted Array** — Same-direction write finger.
3. **Two Sum II** — Sorted partner sum without a hash map.
4. **Container With Most Water** — Prove which side should move.
5. **3Sum** — Fix one + two pointers; careful duplicate skipping.
6. **Trapping Rain Water** — Height bounds from both sides (also DP/stack variants).

## Sliding Window

1. **Maximum Sum Subarray of Size K** — Fixed window warmup.
2. **Longest Substring Without Repeating Characters** — Variable window + map.
3. **Fruits Into Baskets** — At most 2 kinds classic.
4. **Permutation in String** — Fixed window frequency match.
5. **Minimum Window Substring** — Need-count / have-count hard version.
6. **Sliding Window Maximum** — Deque monotonic queue bridge.

## Fast & Slow Pointers

1. **Linked List Cycle** — Meeting proof intuition.
2. **Middle of the Linked List** — Fast hits null ⇒ slow is mid.
3. **Happy Number** — Function graph cycle.
4. **Linked List Cycle II** — Find entrance after they meet.
5. **Find the Duplicate Number** — Array acts like a next-pointer graph.

## Linked List Pointer Manipulation

1. **Reverse Linked List** — prev/curr/next muscle memory.
2. **Merge Two Sorted Lists** — Dummy head pattern.
3. **Remove Nth Node From End** — Gap pointer or two-pass.
4. **Swap Nodes in Pairs** — Rewire in groups of 2.
5. **Reverse Nodes in k-Group** — Count, reverse block, reconnect.
6. **Merge k Sorted Lists** — See also Heap for multi-way merge.
