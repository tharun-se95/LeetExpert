# Family 6 — Practice Shortlist

Aim: **5–8 drills per pattern**. One line = why it matters for recognition.

## BFS

1. **Binary Tree Level Order** — Queue layers; the BFS entry point.
2. **Rotting Oranges** — Multi-source minutes from every rotten orange.
3. **Shortest Path in Binary Matrix** — Grid BFS; first visit = distance.
4. **Open the Lock** — Hidden graph; neighbors are dial turns.
5. **Word Ladder** — Dictionary edges; hard unweighted shortest path.
6. **Bus Routes** — Model stops/buses carefully before BFS.

## Graph Traversal

1. **Find if Path Exists** — Adj list + visited hygiene baseline.
2. **Clone Graph** — Map old→new while walking; watch representation.
3. **Is Graph Bipartite?** — Color with BFS/DFS; odd cycle ⇒ no.
4. **Number of Connected Components** — Restart walk from every unvisited.
5. **Keys and Rooms** — Reachability on rooms graph (keys as edges).
6. **Course Schedule** — Dual-home: traversal/colors angle; topo owns finish order.

## Union Find

1. **Number of Provinces** — Matrix unions; count roots.
2. **Redundant Connection** — First edge that fails union.
3. **Graph Valid Tree** — n−1 edges + one component.
4. **Accounts Merge** — Email graph UF; merge then assemble.
5. **Swim in Rising Water** — UF (or Dijkstra) on rising threshold.
6. **Earliest Moment When Everyone Become Friends** — Sort friendships; Kruskal-style.

## Topological Sort

1. **Course Schedule** — Cycle detection (indegree / colors).
2. **Course Schedule II** — Emit a valid order, not just yes/no.
3. **Alien Dictionary** — Build letter graph, then Kahn/DFS topo.
4. **Parallel Courses III** — Time along topo (longest path on DAG).
5. **Sequence Reconstruction** — Unique topo order constraints.
6. **Find Eventual Safe States** — Safe nodes via reverse / cycle trim.

## Dijkstra

1. **Network Delay Time** — Canonical non-negative shortest path.
2. **Path With Minimum Effort** — Edge weight = effort; min-max path.
3. **Cheapest Flights Within K Stops** — Constrained Dijkstra / DP hybrid.
4. **Swim in Rising Water** — Dijkstra alternative to UF thresholding.
5. **Path with Maximum Probability** — Max-product via log or priority queue.
6. **The Maze II** — Roll until wall; distance is steps, not hops.

## MST

1. **Min Cost to Connect All Points** — Kruskal (or Prim) on dense points.
2. **Connecting Cities With Minimum Cost** — Classic edge-list MST; −1 if disconnected.
3. **Optimize Water Distribution** — Virtual well node + MST.
4. **Earliest Moment When Everyone Become Friends** — Sorted edges + UF (Kruskal shape).
5. **Find Critical and Pseudo-Critical Edges in MST** — Hard; classify MST edges.
6. **Min Cost to Connect All Points (Prim)** — Grow from one seed with a heap; same answer, different recognition.
