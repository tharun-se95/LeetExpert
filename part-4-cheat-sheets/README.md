## Card Format

Each pattern card includes:

- Recognition keywords (what makes you think of this pattern)
- Complexity (Time / Space — how work and memory grow)
- Data Structure
- Difficulty (typical) · Interview Frequency
- Short Template (generic pseudocode, ~5–10 lines)
- Common Questions (3–5 names)
- Common Mistakes (2–3 bullets, optional)

## How to Review

1. Cover the template; say the pattern name from the recognition line alone.
2. Uncover and rewrite the template from memory in 60 seconds.
3. Misses → reread the Mental Model in Part 2 (not just the template).
