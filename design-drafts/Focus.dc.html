The problem

Remove duplicates
from a sorted array

The array arrives sorted. Remove the duplicates in place so that every unique element appears exactly once, and the order they came in survives.

Return k, the number of unique elements. Nothing past nums[k] is ever read — you may leave whatever you like there.

def remove_duplicates(nums):
    # w — where the next unique value lands
    w = 1
    for r in range(1, len(nums)):
        if nums[r] != nums[w - 1]:
            nums[w] = nums[r]
    return w
