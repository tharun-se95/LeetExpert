# Getting Started — analogy draft

Hand-authored (not run through NotebookLM — the module is meta/onboarding
content, not a CS mechanism, so a live drafting pass wasn't needed; the
style guide's rules still applied by hand). Throughline: learning to
*cook* — technique over memorized recipes — sustained across all 4
lessons.

## Lesson 1 — Course Introduction
**Analogy:** Two cooks — one who memorized fifty recipes verbatim (can
only make those fifty exact dishes), one who learned technique (heat,
resting, salt) and can improvise from any ingredients.
- Mastery vs. pattern recognition = the technique-cook vs. the
  recipe-reciter
- Mechanics before use = learning how the pan/knife actually behaves
  before being handed a dish
- Costs come with reasons = never told "sear 3 minutes" without being
  told why
- You implement everything = actually cooking it yourself, hands in the
  kitchen
- Expectations (can already program / attempt before reading / honest
  quizzes) = already knowing kitchen safety / tasting your own dish
  before checking the demo / grading your own cooking honestly

## Lesson 2 — How Lessons & Problems Work
**Analogy:** A cooking class's two session types — demonstration (chef
shows technique) and cook-off (you're handed ingredients, attempt solo,
compare after).
- Concept lessons = demonstrations
- Problem lessons = cook-offs
- Code tabs = the same dish cooked two styles side by side
- Complexity boxes = the nutrition label
- Reveals = tasting notes read only after cooking
- Quizzes = the taste test

## Lesson 3 — Writing & Running Code
**Analogy:** Your own kitchen station, pre-stocked for the cook-off.
- Starter code = labeled ingredients already laid out
- Language toggle = French style vs. Italian style, mise en place kept
  separate per style
- Run = the stove lights up
- Test cases = a full panel of taste-testers, not one bite
- Tests/Console/Insight tabs = which dish came back wrong / a quick
  mid-cook taste / the technique card
- Coach = a sous chef tasting your dish and pointing at what's off,
  without handing you the finished plate
- Reset = clearing your station, other language's prep untouched

## Lesson 4 — The Roadmap
**Analogy:** A five-course culinary training menu, each course building
on the hands the last one trained.
- Stage 0 = knife skills and pantry basics
- Stage 1 = the raw ingredients every later dish is built from
- Stage 2 = techniques applied to those same ingredients
- Stage 3 = composed dishes built from smaller cooked components
- Stage 4 = the full tasting menu, every skill working together at once
