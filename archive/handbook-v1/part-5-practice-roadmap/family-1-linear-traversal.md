# Family 1 — Practice Shortlist

## Arrays

1. **Move Zeroes** — Compact in place without scrambling relative order.
2. **Rotate Array** — Index math / reverse trick without an extra O(n) array.
3. **Product of Array Except Self** — Prefix/suffix products; no division cheat.
4. **Spiral Matrix** — Walk with shrinking borders; classic matrix loop.
5. **First Missing Positive** — Mark presence in place; interview-hard flavor.

## Hash Maps

1. **Two Sum** — Partner lookup in a map; the golden first map problem.
2. **Valid Anagram** — Letter counts (fixed alphabet or general map).
3. **Isomorphic Strings** — Two-way mapping (or map + set).
4. **Group Anagrams** — Design a key (sorted string or count tuple).
5. **Longest Consecutive Sequence** — Set membership for O(n) streak starts.

## Hash Sets

1. **Contains Duplicate** — Insert while scanning; pure membership.
2. **Intersection of Two Arrays** — Set overlap on two collections.
3. **Happy Number** — Seen-set catches cycles (compare Fast/Slow later).
4. **Find All Numbers Disappeared** — Set or in-place mark hybrid.
5. **Longest Consecutive Sequence** — Set-only version; no counts needed.

## Prefix Sum

1. **Range Sum Query Immutable** — Build once; answer many queries in O(1).
2. **Find Pivot Index** — Total sum vs running left sum.
3. **Subarray Sum Equals K** — Prefix frequencies; the core combo pattern.
4. **Contiguous Array** — Prefix of +1/−1 with first-seen index map.
5. **Maximum Size Subarray Sum Equals k** — Prefix + map for longest length.
