## Caption

Do any two of 1,000 meetings clash? You don't compare 499,500 pairs. You sort, and compare 999 neighbours.

Can one person attend every meeting? Only if no two overlap, and a meeting that ends exactly when the next begins is fine.

Comparing every pair of 1,000 meetings is 499,500 comparisons when nothing clashes. Sort by start first, and you compare each meeting only with the one before it: 999 comparisons.

Why that is enough: say meeting j overlaps some earlier meeting i. The meeting right before j starts no earlier than i and no later than j, so i is still running when it starts too. Push that down and some adjacent pair must clash. So if no neighbours clash, nothing does.

One detail: the comparison is <, not <=. With <=, [[1,5],[5,8]] is wrongly rejected.

Where else does sorting turn an all-pairs question into a neighbour question? 👇

## Alt text (per slide)

**Slide 1.** Cover. Intervals. 499,500 pairs of meetings. Check 999. Sort by start, and overlap becomes a question about neighbours.

**Slide 2.** The problem. Can one person attend them all? Only if no two meetings overlap. One ending exactly when another begins is fine. [[0,30],[5,10],[15,20]]: false. [[7,10],[2,4]]: true.

**Slide 3.** Brute force. Compare every pair Python code: def can_attend_brute(intervals): / for i in range(len(intervals)): / for j in range(i + 1, len(intervals)): / a, b = intervals[i], intervals[j] / if max(a[0], b[0]) < min(a[1], b[1]): / return False / return True. 1,000 meetings, nothing clashes: 499,500 pairs compared.

**Slide 4.** The insight. Sort, and it's a neighbour question Sort by start. If two meetings anywhere in the list overlap, then two *adjacent* meetings must overlap. So one pass decides it: compare each meeting's start against the previous meeting's end. That end is the only state you carry.

**Slide 5.** The code. One sort, one pass Python code: def can_attend_meetings(intervals: list[list[int]]) -> bool: / intervals.sort(key=lambda iv: iv[0]) / for i in range(1, len(intervals)): / if intervals[i][0] < intervals[i - 1][1]: / return False / return True. <, not <=: with <=, [[1,5],[5,8]] would be wrongly rejected.

**Slide 6.** Why it holds. Why neighbours are enough Say meeting *j* overlaps some earlier meeting *i*. The meeting right before *j* starts no earlier than *i* and no later than *j*. So *i* is still running when it starts too. Push that down and some adjacent pair must clash. If no adjacent pair clashes, no pair does.

**Slide 7.** Count it. 1,000 meetings, nothing clashes Every pair: 499,500 comparisons. Sort, then neighbours: 999 comparisons. The sort costs O(n log n). The scan after it carries one value.
