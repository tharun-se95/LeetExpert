## Alt text (per slide)

**Slide 1.** Cover. A leetExpert cheatsheet titled "Arrays & Dynamic Arrays", with a "Save this" tag. Tagline: "In-place discipline — write pointers, partitions, one pass." Chips list what is inside: 5 smells to patterns, 5 patterns, 3 targets and 2 traps.

**Slide 2.** Smell to pattern. Sorted array, remove / unique in place → Write pointer. Reorder around a predicate (zero / pivot) → Partition. Rotate or reverse cycles, O(1) space → Triple reverse. Best of something over a scan → Running extreme. Answer needs left×right without division → Prefix / suffix.

**Slide 3.** Pattern 1 of 5: Write pointer. When: Compact valid elements to the front. Read with one index, write with another. Everything left of write is the answer region; never allocate a second array.

**Slide 4.** Pattern 2 of 5: Partition pointers. When: Stable reorder by a boolean test. Grow a ‘kept’ region from the left. Swap (or assign) when the predicate holds; watch relative order if the problem demands stability.

**Slide 5.** Pattern 3 of 5: Triple reverse. When: Rotate by k with O(1) extra memory. Reverse whole → reverse prefix → reverse suffix. Normalise k mod n before indexing; empty and n=1 are free no-ops.

**Slide 6.** Pattern 4 of 5: Running minimum / maximum. When: Optimal pair from a left-to-right scan. Track the best so far while scanning once. The sell/buy (or similar) day ordering is an invariant — encode it in the scan direction.

**Slide 7.** Pattern 5 of 5: Prefix × suffix products. When: Each index needs product of all others. Build left products, then fold right products on a second pass. Division tricks die on zeroes — don’t use them.

**Slide 8.** Targets, time and extra space. Write / partition pass: O(n) time, O(1) space (Target for in-place drills). Triple reverse rotate: O(n) time, O(1) space (Three linear reverses). Prefix / suffix products: O(n) time, O(1)* space (*output array doesn’t count). Traps. Off-by-one on the write index: Decide whether write points at the next free slot or the last written one — and stick to it. Mixing the two is the usual silent corruption. k can exceed n: Any rotate or index arithmetic that ignores k %= n will read off the end. Normalise before you touch the array.

**Slide 9.** Closing slide: "The real Arrays & Dynamic Arrays cheatsheet, from the course." One of 21 cheatsheets in leetExpert, the interactive DSA course, each under its module's practice problems. leetexpert.com, link in bio.
