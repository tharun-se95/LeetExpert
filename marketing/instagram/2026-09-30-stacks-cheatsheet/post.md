## Alt text (per slide)

**Slide 1.** Cover. A leetExpert cheatsheet titled "Stacks", with a "Save this" tag. Tagline: "LIFO for nesting, deferred work, and monotonic candidates." Chips list what is inside: 5 smells to patterns, 4 patterns, 3 targets and 2 traps.

**Slide 2.** Smell to pattern. Valid parentheses / nesting → Push open, match close. Next greater / smaller element → Monotonic stack. Evaluate expression / calculator → Values + ops stacks. Histogram / largest rectangle → Mono heights + widths. Decode nested strings → Stack of frames.

**Slide 3.** Pattern 1 of 4: Match nesting. When: Brackets, tags, or nested scopes. Push opening symbols; on close, pop and check the pair. Empty stack at the end ⇔ balanced. A leftover opener is also a fail.

**Slide 4.** Pattern 2 of 4: Monotonic stack. When: Next greater / smaller to the right (or left). Keep indices in increasing or decreasing value order. When a new value breaks the mono invariant, pop — each pop answers ‘next’ for that index.

**Slide 5.** Pattern 3 of 4: Deferred evaluation. When: Infix expression or running calculator. Hold operators until precedence (or a ‘)’) says apply. Two stacks — values and ops — cover most interview expression drills.

**Slide 6.** Pattern 4 of 4: Frame stack decode. When: Nested repeats like 3[a2[c]]. Push a frame (count, partial string) when you enter a bracket; pop and multiply when you leave. The stack depth mirrors nesting.

**Slide 7.** Targets, time and extra space. Linear scan + stack: O(n) time, O(n) space (Each index push/pop ≤ once). Nested structure walk: O(n) time, O(h) space (h = nesting depth). Monotonic next-greater: O(n) time, O(n) space (Amortised one pop per index). Traps. Peeking an empty stack: Always guard pop/top. Empty means unmatched closer or no candidate yet — both are meaningful states, not just crashes. Storing values instead of indices: Monotonic ‘next greater’ usually needs indices (for distance or later writes). Storing only values loses where the answer belongs.

**Slide 8.** Closing slide: "The real Stacks cheatsheet, from the course." One of 21 cheatsheets in leetExpert, the interactive DSA course, each under its module's practice problems. leetexpert.com, link in bio.
