## Alt text (per slide)

**Slide 1.** Cover. A leetExpert cheatsheet titled "Hash Tables", with a "Save this" tag. Tagline: "O(1) average lookup turns nested scans into one pass." Chips list what is inside: 5 smells to patterns, 5 patterns, 3 targets and 2 traps.

**Slide 2.** Smell to pattern. Need complement / pair for a target → Value → index map. Duplicate inside a distance k → Sliding last-seen. First unique / order of appearance → Count then scan. Group by signature → Key = sorted / count tuple. Long consecutive run without sort → Set + expand ends.

**Slide 3.** Pattern 1 of 5: Complement map. When: Two-sum family. As you scan, ask ‘have I seen target − x?’ Store value → index. One pass; don’t forget you cannot reuse the same index.

**Slide 4.** Pattern 2 of 5: Last-seen index window. When: Duplicates with distance constraint. Map value → latest index. When the gap ≤ k, you have a hit. Overwrite the index as you go.

**Slide 5.** Pattern 3 of 5: Count then first pass. When: First unique character / element. Frequency map first, then a stable left-to-right scan for count == 1. Order matters — maps alone lose it.

**Slide 6.** Pattern 4 of 5: Canonical key grouping. When: Anagrams / isomorphic buckets. Hash a sorted string or a count signature. Every member of a group shares one key — append to that list.

**Slide 7.** Pattern 5 of 5: Set + expand consecutive. When: Longest consecutive sequence. Put numbers in a set. Only start a run at n when n−1 is absent — then walk n+1… Length is the walk count.

**Slide 8.** Targets, time and extra space. One-pass complement: O(n) time, O(n) space (Average hash time). Group by signature: O(n·k log k) time, O(n·k) space (k = key length if sorting). Consecutive via set: O(n) time, O(n) space (Each run starts once). Traps. Hashing unhashable structures: Lists aren’t keys — freeze them (tuple / sorted string / joined counts) before inserting into a map. Average vs worst case: Interview answers assume average O(1). Pathological collisions exist; still state the average unless asked for worst-case structures.
