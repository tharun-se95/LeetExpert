## Caption

Move every zero to the end of an array, in place, without shifting anything twice.

Move Zeroes: push every 0 to the end, keep the other numbers in order, use O(1) extra space.

The tempting way: find a zero, shift everything after it left, drop the zero at the end. Correct, and accidentally quadratic.

The insight: zeroes are all identical, so they don't need carrying. Compact the non-zeroes to the front with a write pointer, then fill the tail with zeroes.

On 1,000 numbers with every other one a zero, that's 1,000 writes against 375,250 for the shuffle: 375 times fewer.

There's a one-pass swap version too. Which would you write? 👇

## Alt text (per slide)

**Slide 1.** Cover. Arrays & Dynamic Arrays. Move the zeroes to the end. No second array. And without shifting the whole array on every zero.

**Slide 2.** The problem. In place, order kept nums: [0, 1, 0, 3, 12]. After: [1, 3, 12, 0, 0]. O(1) auxiliary space: building a new array fails the requirement.

**Slide 3.** The tempting way. Shift left on every zero Find a zero, shift everything after it one step left, place the zero at the end. Correct, and *accidentally quadratic*: every zero moves the rest of the array.

**Slide 4.** The insight. Zeroes don't need carrying They are all identical, so they can be *reconstructed*. Compact the non-zeroes to the front, in order. Then fill the tail with zeroes.

**Slide 5.** The code. One write pointer Python code: def move_zeroes(nums): / w = 0 / for r in range(len(nums)): / if nums[r] != 0: / nums[w] = nums[r] / w += 1 / while w < len(nums): / nums[w] = 0 / w += 1. Everything before w is a non-zero, in order. Whatever is left past w gets overwritten with zeroes.

**Slide 6.** Count the writes. 1,000 numbers, every other one a zero Shift left on every zero: 375,250 writes. Compact, then fill: 1,000 writes. One write per slot, however many zeroes there are.
