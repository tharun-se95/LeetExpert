## Caption

How does a build system know what to compile first? It sorts a graph.

To build a source file you must first build the modules it imports. Model each file as a vertex and each "A before B" as an edge A → B. A topological sort is an order in which every edge points forward.

Kahn's algorithm: anything with no unmet dependencies is safe to place. Place it, remove its edges, and whatever just dropped to zero dependencies is ready next.

Four files, four imports (utils → lexer, utils → parser, lexer → app, parser → app) come out as utils → lexer → parser → app.

And the cycle check is free: make app a dependency of utils and 0 of the 4 files can ever be built. The order comes up short, so no valid order exists.

Where else have you met this? Course prerequisites, spreadsheet cells… 👇

## Alt text (per slide)

**Slide 1.** Cover. Graphs. How does a build system know what to compile first? It sorts a graph.

**Slide 2.** The model. Tasks are vertices. "Before" is an edge. To build a source file you must first build the modules it imports. Draw A → B for "A must come before B". A *topological sort* is an order where every edge points forward.

**Slide 3.** The idea. Start with what depends on nothing A vertex with in-degree zero has no unmet dependencies, so it is safe to place first. Place it, remove its edges, and whatever just dropped to zero is ready next.

**Slide 4.** Kahn's algorithm. BFS by in-degree Python code: while queue: / u = queue.popleft() / order.append(u) / for v in adj[u]: / indegree[v] -= 1 / if indegree[v] == 0: / queue.append(v) / return order if len(order) == num_vertices else None. The queue starts with every vertex whose in-degree is zero. Each one placed can free the vertices it points to.

**Slide 5.** Run it. 4 files, 4 imports Must come before: utils → lexer, utils → parser, lexer → app, parser → app. Build order: utils → lexer → parser → app.

**Slide 6.** The free check. A cycle has no starting point Make app a dependency of utils: 0 of 4 files can be built. A vertex on a cycle never reaches in-degree zero. If the order comes up short, no valid order exists.

**Slide 7.** Closing slide. From the course: Topological Sort, a lesson in Graphs, in leetExpert, the interactive DSA course. Then the DFS version, and why only a DAG can be ordered. leetexpert.com, link in bio.
