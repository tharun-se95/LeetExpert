## Caption

Feed a binary search tree sorted data and it quietly becomes a linked list.

Every BST operation costs O(h), where h is the tree's height. That's only fast if the tree's shape cooperates.

Insert 1, 2, 3, 4, 5 in order: every insert turns right, and you get 5 levels for 5 keys. Finding 5 visits all 5 nodes.

At 1,000 sorted keys: 1,000 levels, 1,000 nodes visited to find the largest. Build the same keys middle-first and it's 10 levels.

And sorted input isn't exotic: ordered files, timestamps, an already-sorted array. That's why real libraries don't hope for balance. They restore it with rotations.

Which self-balancing tree did you learn first? 👇

## Alt text (per slide)

**Slide 1.** Cover. BST & Ordered Structures. Feed a BST sorted data and it becomes a linked list. Every promise still true. All of them worthless.

**Slide 2.** The promise. Every BST operation is O(h) h is the height, and it is only small if the tree's shape cooperates. A *balanced* tree guarantees h = O(log n). No binary tree can be shorter than about log₂ n.

**Slide 3.** The break. Insert 1, 2, 3, 4, 5 in order Every insert turns right, because every value is larger than everything already there. The tree collapses into a straight line. Levels: 5. Nodes visited to find 5: 5.

**Slide 4.** The code is fine. A correct insert Python code: def insert_into_bst(root, val): / if root is None: / return TreeNode(val) / node = root / while True: / if val < node.val: / if node.left is None: / node.left = TreeNode(val) / return root / node = node.left / else: / if node.right is None: / node.right = TreeNode(val) / return root / node = node.right. Nothing here is wrong. The shape comes from the order of the input.

**Slide 5.** At scale. 1,000 keys Inserted in sorted order: 1,000 levels · O(n) search. Same keys, built middle first: 10 levels · O(log n) search.

**Slide 6.** Why it matters. Sorted input is not exotic Data loaded from an ordered file, timestamps arriving in order, an already-sorted array inserted one element at a time. So real libraries don't hope for balance. They restore it as the tree changes, *with rotations*.
