## Caption

How many separate networks are hiding inside one graph? Count the flood-fills.

Number of Provinces: n cities, a matrix saying which pairs are directly connected, and a province is any group connected directly or indirectly. How many provinces?

Strip the story away and it's counting connected components. Scan every city; an unvisited one is a new province. Flood-fill from it so its whole group is never counted again.

6 cities with links 0–1, 1–2, 3–4: the answer is 3, the groups {0, 1, 2} {3, 4} {5}. Cities 0 and 2 aren't directly connected, but 1 joins them.

Same skeleton as Number of Islands. And Union-Find answers it a completely different way.

## Alt text (per slide)

**Slide 1.** Cover. Graphs. How many separate networks are hiding in one graph? Count the flood-fills, not the cities.

**Slide 2.** The problem. Cities, connections, provinces isConnected[i][j] = 1 means city i and city j are directly connected. A province is a group of directly *or indirectly* connected cities. How many are there?

**Slide 3.** The reframe. It is counting connected components Scan every city. An unvisited one is a new province. Flood-fill from it, marking every city reachable, so they are never counted again.

**Slide 4.** The code. One counter, one flood-fill Python code: def find_circle_num(is_connected): / n = len(is_connected) / seen = [False] * n / count = 0 / for start in range(n): / if seen[start]: / continue / count += 1 / stack = [start] / seen[start] = True / while stack: / node = stack.pop() / for j in range(n): / if is_connected[node][j] == 1 and not seen[j]: / seen[j] = True / stack.append(j) / return count.

**Slide 5.** Run it. 6 cities, links 0–1, 1–2, 3–4 Provinces: {0, 1, 2} {3, 4} {5}. Flood-fills started: 3. 0 and 2 are not directly connected, but 1 joins them: one province.

**Slide 6.** Same skeleton. You have seen this before It is structurally identical to Number of Islands: scan for unvisited, flood-fill the whole component, increment a counter. Union-Find answers the same question an entirely different way.

**Slide 7.** Closing slide. From the course: Number of Provinces, a lesson in Graphs, in leetExpert, the interactive DSA course. Solve it both ways, with DFS and with Union-Find. leetexpert.com, link in bio.
