## Alt text (per slide)

**Slide 1.** Cover. A leetExpert cheatsheet titled "Graphs", with a "Save this" tag. Tagline: "Nodes + edges — BFS for short, DFS for components, Union-Find for merges." Chips list what is inside: 5 smells to patterns, 4 patterns, 3 targets and 2 traps.

**Slide 2.** Smell to pattern. Shortest path, unweighted → BFS. Connected components / cycle → DFS or Union-Find. Topological order / course schedule → Kahn or DFS postorder. Edges stream in; connectivity queries → Union-Find. Grid islands / regions → DFS/BFS flood.

**Slide 3.** Pattern 1 of 4: BFS shortest. When: Unweighted (or equal-weight) distance. Queue + dist (or layer count). First time you reach a node is optimal — don’t relax it again. Mark seen when enqueued, not when dequeued, to avoid duplicates.

**Slide 4.** Pattern 2 of 4: DFS components. When: Count islands, colour regions, detect cycles. Flood from each unvisited node. Mark visited to avoid revisits. On directed graphs, cycle detection needs a recursion-stack (or colours), not only a visited set.

**Slide 5.** Pattern 3 of 4: Union-Find. When: Merge sets; ask ‘same component?’. find(u) with path compression; union by rank/size. Perfect when edges arrive as pairs and you rarely need full adjacency.

**Slide 6.** Pattern 4 of 4: Topo sort (Kahn). When: Order tasks with prerequisites. Queue zero-indegree nodes; peel outgoing edges. Cycle ⇔ you finish with fewer than V nodes ordered. DFS postorder is the dual.

**Slide 7.** Targets, time and extra space. BFS / DFS: O(V+E) time, O(V) space (Adj list assumed). Union-Find (α): ≈ O(E α(V)) time, O(V) space (Nearly linear). Kahn topo: O(V+E) time, O(V) space (Indegree array + queue). Traps. Directed vs undirected edges: Adding both directions on a directed problem invents paths that don’t exist. Match the statement — and build the adj list the same way. Marking visited too late: In BFS, mark when you enqueue. Marking only on dequeue lets the same node sit in the queue many times and blows time on dense graphs.

**Slide 8.** Closing slide: "The real Graphs cheatsheet, from the course." One of 21 cheatsheets in leetExpert, the interactive DSA course, each under its module's practice problems. leetexpert.com, link in bio.
