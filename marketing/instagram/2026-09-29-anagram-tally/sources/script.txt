Stop sorting to check anagrams. Listen and silent: same letters? Most people sort both words and compare. It works, but sorting costs O of N log N. Think Scrabble instead. Two racks of tiles. You wouldn't alphabetize them. You'd grab a tally sheet. Listen: each tile adds one. Silent: each tile takes one away. Every row back to zero? Same tiles. Anagram. That's one pass, O of N. On a million letters, in our test run, sorting took over two hundred milliseconds. Counting took about a quarter of that. Warehouses reconcile stock the same way: plus one for every box in, minus one for every box out. Bonus: check the lengths first. If they differ, you're done. The catch? The classic twenty-six slot array only covers A to Z. Give it café, and Python crashes: list index out of range. JavaScript is worse: it quietly says false. Beyond A to Z, count with a hash map. And never compare sets. A A C C and C C A C have the same set of letters, but they're not anagrams. Counts matter. Hear same letters, any order? Say count them, out loud.
