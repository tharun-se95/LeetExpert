## Caption

Always take the biggest coin that fits. It feels optimal. With coins 1, 3 and 4, it isn't.

Fewest coins to make an amount. The obvious plan: take the largest coin that fits, repeat. On coins 1, 2, 5 making 11 it gives 5 + 5 + 1, 3 coins, and that's optimal.

Now coins 1, 3, 4 and amount 6. Greedy takes 4 + 1 + 1: 3 coins. The best is 3 + 3: 2 coins.

Greedy commits to one choice per step and never reconsiders it. Dynamic programming tries every possible last coin and keeps the minimum.

With those coins, greedy uses more coins than needed on 24 of the amounts from 1 to 100. A plausible-looking greedy rule needs a proof before you trust it.

Can you name coins where greedy is always right? 👇

## Alt text (per slide)

**Slide 1.** Cover. Dynamic Programming. Always take the biggest coin. It feels optimal. It isn't. Coins 1, 3 and 4. Make 6.

**Slide 2.** The obvious plan. Largest coin that fits, repeat Python code: def greedy_change(coins, amount): / used = [] / for c in sorted(coins, reverse=True): / while amount >= c: / amount -= c / used.append(c) / return used if amount == 0 else None. Coins 1, 2, 5 making 11: it gives 5 + 5 + 1, which is 3 coins, and that is optimal.

**Slide 3.** The counterexample. Coins 1, 3, 4. Make 6. Greedy: 4 + 1 + 1 · 3 coins. Best: 3 + 3 · 2 coins.

**Slide 4.** Why. Greedy commits and never reconsiders It makes one choice at each step, the largest coin, and never revisits it. A locally appealing choice that leads to a worse overall result is never corrected.

**Slide 5.** The fix. Try every possible last coin Python code: def coin_change(coins, amount): / INF = amount + 1 / dp = [0] + [INF] * amount / for a in range(1, amount + 1): / for c in coins: / if c <= a and dp[a - c] + 1 < dp[a]: / dp[a] = dp[a - c] + 1 / return -1 if dp[amount] >= INF else dp[amount]. dp[a] is the fewest coins for amount a: one more than the best dp[a - c] over every coin c.

**Slide 6.** How often. Coins 1, 3, 4, amounts 1 to 100 Greedy uses more coins than needed: 24 of 100 amounts. A plausible-looking greedy rule needs a proof before you trust it.
