## Caption

There are 4,426,165,368 ways to put 8 queens on a chessboard. Backtracking finds every solution after placing 2,056.

Place n queens on an n by n board so that no two share a row, a column or a diagonal.

The naive way chooses any 8 of the 64 cells and validates the whole board only once a full placement is proposed. That is 4,426,165,368 candidates.

First prune: no two queens can share a row, so each row gets exactly one, and the only choice is which column. Second: check a placement before making it. Along one diagonal direction row - col is constant, along the other row + col is, so three sets answer 'is this square attacked?' in O(1).

Choose, explore, unchoose: 2,056 queens placed, all 92 solutions found. A dead end is abandoned at the first conflict, with everything that would have been built on top of it.

## Alt text (per slide)

**Slide 1.** Cover. Recursion & Backtracking. 4,426,165,368 ways to place 8 queens. Backtracking tries 2,056. What pruning is worth, counted.

**Slide 2.** The problem. n queens, none attacking No two queens share a row, a column or a diagonal. For n = 4 there are 2 boards: The two solutions for a 4 by 4 board, drawn as dots and Qs, one queen in each row and column.

**Slide 3.** Brute force. Choose 8 of 64 cells Candidate placements: 4,426,165,368. Each needs a pairwise check, and the whole board is validated only once a full placement is proposed.

**Slide 4.** First prune. One queen per row No two queens can share a row, so each row gets exactly one. The choice at each level is *which column*. 1 of 8 columns, 8 times: 16,777,216.

**Slide 5.** The check. Is this square attacked? Along one diagonal direction row - col is constant. Along the other, row + col is. So keep three sets: used columns, used row - col, used row + col. A placement is legal exactly when all three are absent. Three O(1) lookups instead of a scan over every queen placed so far.

**Slide 6.** The code. Choose, explore, unchoose Python code: def place(row, n, cols, d1, d2): / if row == n: / return 1 / found = 0 / for col in range(n): / if col in cols or row - col in d1 or row + col in d2: / continue / cols.add(col) / d1.add(row - col) / d2.add(row + col) / found += place(row + 1, n, cols, d1, d2) / cols.remove(col) / d1.remove(row - col) / d2.remove(row + col) / return found.

**Slide 7.** Count it. 8 queens Choose 8 of 64 cells: 4,426,165,368. One per row, no pruning: 16,777,216. Queens placed by backtracking: 2,056. Solutions found: 92.
