## Caption

A heap is a tree with no pointers. Just an array and three lines of arithmetic.

A heap is always a complete binary tree: every level full except possibly the last, and the last filled left to right with no gaps.

Number the nodes in reading order and write them into an array. A node at index i has its children at 2i + 1 and 2i + 2, and its parent at (i − 1) // 2. No pointer is ever stored.

In [1, 3, 2, 7, 4, 5, 8], index 1's children are indices 3 and 4 (values 7 and 4), and index 6's parent is index 2.

It only works because there are no gaps. And it saves real memory: a pointer-based tree of 1,000,000 nodes spends 16,000,000 bytes on child references alone.

Did you know the heap in your standard library is just a list? 👇

## Alt text (per slide)

**Slide 1.** Cover. Heaps. A heap is a tree with no pointers. Just an array and three lines of arithmetic.

**Slide 2.** The rule. Complete: no gaps, ever Every level is entirely full except possibly the last, and the last is filled strictly left to right. Number the nodes in reading order, write them into a flat array, and the whole tree is still there.

**Slide 3.** The arithmetic. Three index helpers Python code: def parent(i: int) -> int: / return (i - 1) // 2 / def left(i: int) -> int: / return 2 * i + 1 / def right(i: int) -> int: / return 2 * i + 2. A node's parent and children are found by pure index arithmetic. Not a single pointer is stored.

**Slide 4.** Try it. [1, 3, 2, 7, 4, 5, 8] Children of index 1: indices 3 and 4 · values 7 and 4. Parent of index 6: index 2 · value 2. Every parent is no bigger than its children: a min-heap, stored flat.

**Slide 5.** Why no gaps. Completeness is the precondition With no gaps, the level sizes are exact powers of two. That counting is what collapses the algebra to 2i + 1 and 2i + 2. A node missing in the middle of a level would break the arithmetic. Completeness is not cosmetic: it lets the array *be* the tree.

**Slide 6.** What it saves. 1,000,000 nodes Pointer-based tree: child references: 16,000,000 bytes. Array heap: child references: none. Two child references are 16 bytes on a 64-bit machine. For an int-sized payload, the pointers can outweigh the data.
