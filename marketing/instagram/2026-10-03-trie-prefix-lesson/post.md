## Caption

A hash set finds a word in O(1). Ask it what starts with "pre" and it has to check every entry.

A hash set answers one question: is this exact string stored? Autocomplete asks a different one: does anything start with "pre"?

The set scattered "prefix" and "pretend" to unrelated slots on purpose. That's why exact lookup is O(1), and why a prefix query has to test all 10,000 entries: 10,000 checks.

A trie keeps related keys related. Words that share a prefix share the same nodes: car, card, cat, cats is 14 characters stored in 6 nodes. The same prefix query takes 3 steps, one per character, however many words are stored.

And a missing edge ends a search early: looking for "cable" among card and cat stops after 2 of its 5 characters.

Where have you used a trie outside an interview? 👇

## Alt text (per slide)

**Slide 1.** Cover. Tries. Ask a hash set what starts with "pre". It has to check every entry. The property that makes it fast is what makes it useless here.

**Slide 2.** The gap. One question, answered very fast A hash set answers "is this exact string stored?" in O(1) on average. Autocomplete asks something else: "does any stored word start with this?" The set scattered related words to unrelated slots on purpose, so it has nothing to offer.

**Slide 3.** The structure. Shared prefixes share nodes Stored: car, card, cat, cats. Characters across the words: 14. Nodes in the trie: 6. Edges are labelled with characters; a path from the root spells a string.

**Slide 4.** The code. Every operation is one walk Python code: def insert(self, word): / node = self.root / for ch in word: / node = node.setdefault(ch, {}) / node["$"] = True / def _walk(self, s): / node = self.root / for ch in s: / if ch not in node: / return None / node = node[ch]. A missing edge ends the walk at once.

**Slide 5.** The prefix query. 10,000 words. What starts with "pre"? Hash set: entries tested: 10,000. Trie: steps down from the root: 3. The tree gets wider as words are added, never slower to descend.

**Slide 6.** Stopping early. Search for "cable" among card and cat Characters looked at: 2 of 5. After c and a there is no edge for b, so the word was never stored. No point continuing.
