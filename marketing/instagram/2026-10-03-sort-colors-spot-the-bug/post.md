## Alt text (per slide)

**Slide 1.** Spot the bug: Sort Colors (Dutch National Flag). A 12-line Python function, sort_colors: def sort_colors(nums): / low, mid, high = 0, 0, len(nums) - 1 / while mid < high: / if nums[mid] == 0: / nums[low], nums[mid] = nums[mid], nums[low] / low += 1 / mid += 1 / elif nums[mid] == 1: / mid += 1 / else: / nums[mid], nums[high] = nums[high], nums[mid] / high -= 1. It passes the sample test: sort_colors([2, 0, 2, 1, 1, 0]) gives [0, 0, 1, 1, 2, 2]. Find the input that breaks it. Comment it, then swipe.

**Slide 2.** Hint. The same code, with line 3 highlighted. When the loop stops, is every element checked? Look at the one where mid meets high.

**Slide 3.** The input that breaks it: sort_colors([2, 0, 1]). Leaves nums as [1, 0, 2]. It should be [0, 1, 2].

**Slide 4.** The fix. One line changes. while mid < high: becomes while mid <= high:. JavaScript, same bug: while (mid &lt; high) { becomes while (mid &lt;= high) {.

**Slide 5.** Why. mid..high is the part not yet read. When mid == high, one element is still unread, and < skips it. From the course: Sort Colors (Dutch National Flag), in Two Pointers.
