## Alt text (per slide)

**Slide 1.** Cover. A leetExpert cheatsheet titled "Strings", with a "Save this" tag. Tagline: "Two ends, builders, and character counts — not magic regex." Chips list what is inside: 5 smells to patterns, 5 patterns, 3 targets and 2 traps.

**Slide 2.** Smell to pattern. Ignore non-alphanumeric / case → Filter + two pointers. Same letters, different order → Anagram counts. Shared stem across words → Prefix shrink. Words reversed, spaces messy → Split / rebuild. Find needle in haystack → Scan + match window.

**Slide 3.** Pattern 1 of 5: Two-pointer palindrome. When: Symmetric check after cleaning. Advance L/R while skipping noise characters. Compare lowercase forms; stop when they cross.

**Slide 4.** Pattern 2 of 5: Frequency / anagram map. When: Permutation of the same multiset. Count characters (array of 26 or a map). Equal counts ⇔ anagram. Prefer fixed alphabets when the problem allows.

**Slide 5.** Pattern 3 of 5: Longest common prefix. When: Vertical or horizontal shrink. Start from the first string and trim until every word agrees — or compare column-by-column and stop at the first mismatch.

**Slide 6.** Pattern 4 of 5: Reverse words. When: Token order flips, spacing collapses. Identify word spans, then rebuild with a single space. Trim ends; don’t reverse characters inside words unless asked.

**Slide 7.** Pattern 5 of 5: Substring search window. When: First index of a pattern. Slide a candidate start; match character-by-character. Know the naive O(n·m) baseline before reaching for KMP.

**Slide 8.** Targets, time and extra space. Clean + two pointers: O(n) time, O(1) space (Or O(n) if you build a filtered copy). Anagram counts: O(n) time, O(Σ) space (Σ = alphabet size). Naive strStr: O(n·m) time, O(1) space (Acceptable for short needles). Traps. Immutability cost: Repeated string concatenation in a loop is quadratic in some languages. Build with a list/array, then join once. Unicode vs interview alphabet: Problems usually mean ASCII letters/digits. Don’t invent Unicode case folding unless the statement asks.

**Slide 9.** Closing slide: "The real Strings cheatsheet, from the course." One of 21 cheatsheets in leetExpert, the interactive DSA course, each under its module's practice problems. leetexpert.com, link in bio.
