## Caption

Two nodes in a tree. Where do their paths meet? Eight lines find it.

Lowest common ancestor: the deepest node that has both p and q beneath it (a node counts as its own descendant). No ordering to lean on, just structure.

Ask every subtree one question: do you contain p or q? If the left side and the right side both say yes, their paths split at this node. That's the answer.

Everywhere else, a non-null result isn't the answer yet. It's a found target being relayed upward.

On the tree in the slides: 5 and 1 meet at 3, 7 and 4 at 2, and 5 and 4 at 5, because 4 sits under 5.

What's the LCA of 6 and 4? 👇

## Alt text (per slide)

**Slide 1.** Cover. Binary Trees. Two nodes in a tree. Where do their paths meet? The lowest common ancestor, in eight lines.

**Slide 2.** The problem. The deepest node above both A binary tree: 3 at the root with children 5 and 1; 5 has children 6 and 2; 1 has children 0 and 8; 2 has children 7 and 4. 5 and 1 sit in different subtrees of 3, so their lowest common ancestor is 3.

**Slide 3.** The idea. Ask each subtree one question Does this subtree contain p or q? Return the node found, or nothing. If the left side and the right side *both* report a find, the two paths split here. This node is the answer.

**Slide 4.** The code. Postorder search Python code: def lowest_common_ancestor(root, p, q): / if root is None or root is p or root is q: / return root / left = lowest_common_ancestor(root.left, p, q) / right = lowest_common_ancestor(root.right, p, q) / if left and right: / return root / return left or right. Anywhere else, a non-null result is just a found target being relayed upward, not a victory.

**Slide 5.** Run it. On that 9-node tree p = 5, q = 1: 3. p = 7, q = 4: 2. p = 5, q = 4: 5 · 4 is under 5.

**Slide 6.** Why it is right. The deepest point still joined If p is on one side of a node and q on the other, any common ancestor is at or above that node, and the node itself is one. So it is the lowest. One postorder pass: O(n) time, O(h) space for the recursion stack.
