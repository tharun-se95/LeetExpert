## Caption

Looking for an anagram of one string inside another? Don't re-sort every window. Each slide changes two letters: 990,100 characters read becomes 19,900.

Does s2 contain a permutation of s1 as a contiguous substring? Two strings are anagrams exactly when their letter counts match, so slide a window the length of s1 across s2 and compare counts.

Re-reading and sorting every window: with s1 of 100 letters and s2 of 10,000, that is 9,901 windows and 990,100 characters read.

But the window never changes size. Each slide, one character leaves and one enters, so at most 2 letters' counts change. Keep a single number, how many of the 26 letters currently have equal counts, and update it for just those letters. 19,900 characters read, same answer.

It is the fixed-window sum trick with a frequency map underneath instead of a number.

What else can you slide instead of recompute? 👇

## Alt text (per slide)

**Slide 1.** Cover. Sliding Window. Don't re-check the window. Two letters changed. Finding an anagram of one string inside another.

**Slide 2.** The problem. Is an anagram of s1 inside s2? Contains one: ba, at index 3: "ab" in "eidbaooo". Contains none: "ab" in "eidboaoo". Two strings are anagrams exactly when their letter counts match.

**Slide 3.** Brute force. Re-sort every window Python code: def check_inclusion_brute(s1, s2): / k = len(s1) / target = sorted(s1) / for i in range(len(s2) - k + 1): / window = [s2[j] for j in range(i, i + k)] / if sorted(window) == target: / return True / return False. s1 of 100 letters, s2 of 10,000: 990,100 characters read.

**Slide 4.** The insight. The window never changes size It is always len(s1) long. Each slide, one character leaves and one enters. So at most 2 letters' counts change. Keep one number: how many of the 26 letters currently have *equal counts* in the window and in s1.

**Slide 5.** The update. One letter changed? Re-check one letter. Python code: def bump(idx: int, delta: int) -> None: / nonlocal matches / if window[idx] == need[idx]: / matches -= 1 / window[idx] += delta / if window[idx] == need[idx]: / matches += 1. A match can only be broken, or made, at the letter that just changed.

**Slide 6.** The slide. One out, one in Python code: for right in range(k, len(s2)): / left = right - k / bump(ord(s2[left]) - a, -1) / bump(ord(s2[right]) - a, 1) / if matches == 26: / return True. When matches is 26, every letter agrees: the window is an anagram.

**Slide 7.** Count it. 9,901 windows Re-sort every window: 990,100 characters read. Slide the match count: 19,900 characters read. The fixed-window sum trick, with a frequency map underneath instead of a number.
