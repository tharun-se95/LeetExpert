## Caption

Binary search needs a sorted array. This problem has none, and binary search still solves it: 19 checks instead of 500,000.

Koko eats bananas at k per hour, one pile at a time, and has h hours. Find the minimum k that finishes in time.

There is no sorted array here. But a faster speed never takes more hours, so every speed below the answer fails and every speed from it up works. The answers themselves are sorted: no, no, no, yes, yes, yes.

Trying every speed from 1 upward on piles of up to 1,000,000 bananas takes 500,000 checks. Binary search over the speeds takes 19, and lands on the same 500,000.

Three signals that it applies: you are asked for a minimum value that satisfies a condition, you can check a candidate, and once a candidate works, every larger one does.

**Slide 2.** The problem. The slowest speed that still finishes Koko eats k bananas an hour, one pile at a time, and has h hours. Find the minimum k. piles = [3,6,7,11], h = 8: k = 4.

**Slide 3.** No array. Nothing here is sorted. The answers are. Speed 3: 10 hours: too slow. Speed 4: 8 hours: in time. A faster speed never takes more hours. So every speed below the answer fails, and every speed from it up works.

**Slide 4.** The slow way. Try every speed Python code: def brute_speed(piles, h): / speed = 1 / while sum(math.ceil(pile / speed) for pile in piles) > h: / speed += 1 / return speed. Piles of up to 1,000,000, 9 hours: 500,000 speeds checked.

**Slide 5.** The code. Halve the range of speeds Python code: def min_eating_speed(piles: list[int], h: int) -> int: / def hours_needed(speed: int) -> int: / return sum(math.ceil(pile / speed) for pile in piles) / lo, hi = 1, max(piles) / while lo < hi: / mid = lo + (hi - lo) // 2 / if hours_needed(mid) <= h: / hi = mid / else: / lo = mid + 1 / return lo.

**Slide 6.** Count it. Same piles, same answer Try every speed: 500,000 checks. Binary search the speeds: 19 checks. Minimum speed, both ways: 500,000.

**Slide 7.** When it applies. Three signals You are asked for a *minimum value* that satisfies a condition. You can *check a candidate*: here, add up the hours at that speed. Feasibility is *monotonic*: once a speed works, every faster one does.
