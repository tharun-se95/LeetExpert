## Caption

Is 1,000,003 prime? You could try 1,000,001 divisors. Or 999.

To check whether n is prime, the obvious loop tries every divisor from 2 up to n - 1. For 1,000,003 that is 1,000,001 divisions.

But divisors come in pairs. 36 has (1, 36), (2, 18), (3, 12), (4, 9) and (6, 6), and the small member of each pair never exceeds 6, the square root of 36. It can't: if both members were larger than the square root, their product would be larger than n.

So if n has any divisor, it has one at or below its square root. Stop the loop there: 999 divisions, and finishing without finding one is a proof that n is prime.

One caveat: that is the square root of the value, not of the input size. For a 300-digit number it is still hopeless, which is exactly why RSA can rest on factoring being hard.

## Alt text (per slide)

**Slide 1.** Cover. Math for DSA. Is 1,000,003 prime? 999 divisions will tell you. Not 1,000,001. Divisors come in pairs.

**Slide 2.** The question. Is n prime? Python code: def is_prime_slow(n): / if n < 2: / return False / d = 2 / while d < n: / if n % d == 0: / return False / d += 1 / return True. n = 1,000,003: 1,000,001 divisions.

**Slide 3.** The insight. Divisors come in pairs If d divides n, so does n / d. For 36: (1, 36)  (2, 18)  (3, 12)  (4, 9)  (6, 6) The small member never exceeds 6, and 6 is the square root of 36.

**Slide 4.** Why. One of each pair has to be small If both members were larger than the square root of n, their product would be larger than n. But their product *is* n. So if n has any divisor, the loop finds one at or below the square root. If it finishes without finding one, n is prime. *That is a proof, not a guess.*

**Slide 5.** The code. Stop at the square root Python code: def is_prime(n: int) -> bool: / if n < 2: / return False / d = 2 / while d * d <= n: / if n % d == 0: / return False / d += 1 / return True. d * d <= n instead of a square root call: it stays in integer arithmetic.

**Slide 6.** Count it. n = 1,000,003 Every divisor below n: 1,000,001 divisions. Up to the square root: 999 divisions. Both say: prime.

**Slide 7.** The caveat. The root of the value, not of the input A number with 300 digits still has a square root far too large to loop over. Measured against the number of digits, this algorithm is exponential. That is exactly why RSA can rest on factoring being hard.
