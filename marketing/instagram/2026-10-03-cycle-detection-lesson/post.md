## Caption

Find a loop in a linked list with two pointers and no extra memory. One walks, one runs.

A linked list has a cycle when some node's next points back to an earlier node, so walking it never reaches null.

The first answer: remember every node you visit. A revisit means a cycle. Correct, and O(n) space: 10,000 nodes stored for a list of 10,000.

Floyd's tortoise and hare: slow moves one node, fast moves two. No cycle and fast falls off the end. A cycle and both end up inside it, where the gap between them shrinks by exactly one per step, so it must hit zero.

On [3, 2, 0, -4] with the tail linked back to 2, they meet after 3 steps. On 10,000 nodes looping to the head: 10,000 steps, and 2 pointers of memory.

Why must the comparison come after the step, not before? 👇

## Alt text (per slide)

**Slide 1.** Cover. Linked Lists. Find a loop in a linked list with two pointers and no memory. One walks. One runs. If there is a loop, they meet.

**Slide 2.** The problem. A list that never ends A cycle: some node's next points back to an earlier node, so traversal never reaches null. In [3, 2, 0, -4], the last node links back to 2. Walk it and you loop forever.

**Slide 3.** The first answer. Remember every node Walk with a set of visited nodes. A revisit means a cycle; null means none. Correct, and the right first answer. A list of 10,000: nodes stored: 10,000 · O(n) space.

**Slide 4.** The code. One walks, one runs Python code: def has_cycle(head): / slow = fast = head / while fast and fast.next: / slow = slow.next / fast = fast.next.next / if slow is fast: / return True / return False. The comparison is node identity, not value, and it happens after stepping.

**Slide 5.** Why they must meet. The gap shrinks by exactly one Inside the loop, fast gains one step on slow every move. The gap cannot skip from 1 to −1, so it reaches 0. A guaranteed meeting within one lap. No probability, no luck.

**Slide 6.** Count it. 10,000 nodes Tail loops back to the head: steps to meet: 10,000. No cycle: steps until fast falls off: 5,000. Extra memory either way: 2 pointers · O(1).
