## Alt text (per slide)

**Slide 1.** Cover. A leetExpert cheatsheet titled "Binary Trees", with a "Save this" tag. Tagline: "Rooted structure — traverse with intent (order, level, or path)." Chips list what is inside: 4 smells to patterns, 4 patterns, 3 targets and 3 traps.

**Slide 2.** Smell to pattern. Visit every node once → DFS pre/in/post. Per level aggregates → BFS queue. Path / diameter style → DFS return + global. Reconstruct from traversals → Split by inorder root.

**Slide 3.** Pattern 1 of 4: Recursive DFS. When: Combine children with the root. Base null → 0/identity. Combine left and right with the root. Pick pre/in/post for when you use the root value.

**Slide 4.** Pattern 2 of 4: Level-order BFS. When: Averages, zigzags, right-side view. Queue nodes; drain a level size each round. Natural for averages, zigzags, and ‘right side view’.

**Slide 5.** Pattern 3 of 4: Post-order aggregate. When: Height, diameter, LCA prep. Need both children before deciding. Compute below, then update a global answer — don’t decide too early.

**Slide 6.** Pattern 4 of 4: Reconstruct from traversals. When: Preorder + inorder (or the like). Take the root from preorder, split inorder into left/right spans, recurse on each span. The root index bookkeeping is the entire trap.

**Slide 7.** Targets, time and extra space. DFS / BFS visit: O(n) time, O(h) / O(w) space (h height, w width). Path aggregates: O(n) time, O(h) space (One pass with returns). Reconstruct: O(n) time, O(n) space (With index map). Traps. Null child assumptions: Always guard left/right. Many ‘simple’ bugs are dereferencing null on a leaf’s child. Confusing node count with height: Height and depth conventions differ (edges vs nodes). Pick one definition and stick to it in base cases. Reconstruction index drift: Inorder split sizes shrink each level; recompute spans from lengths, not from global positions, or you read off the wrong subtree.

**Slide 8.** Closing slide: "The real Binary Trees cheatsheet, from the course." One of 21 cheatsheets in leetExpert, the interactive DSA course, each under its module's practice problems. leetexpert.com, link in bio.
