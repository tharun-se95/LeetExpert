Binary Search · Edge Case

This loop
never ends

The array is sorted. It is not empty. The target is in it. The search still hangs forever.
def binary_search(arr, target): lo, hi = 0, len(arr) - 1 while lo <= hi: mid = lo + (hi - lo) // 2 if arr[mid] == target: return mid elif arr[mid] < target: lo = mid else: hi = mid - 1 return -1

(1 + 0) // 2 = 0. Truncating division pins mid onto lo whenever the range is two wide. So lo = mid assigns lo to itself, nothing shrinks, and the exit test is never reachable.

The fix — and why it is not style

One character
restores it

lo = mid
lo = mid + 1
Once arr[mid] is ruled out it has to leave the range. That + 1 is what forces the range to shrink on every pass — and a range that always shrinks is a loop that has to end.
Write the loop from its invariant — the answer lies in [lo, hi] — and this bug is not one you can write.
