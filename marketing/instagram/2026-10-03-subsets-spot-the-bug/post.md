## Alt text (per slide)

**Slide 1.** Spot the bug: Subsets. A 12-line Python function, subsets: def subsets(nums): / result, path = [], [] / def backtrack(start): / result.append(path) / for i in range(start, len(nums)): / path.append(nums[i]) / backtrack(i + 1) / path.pop() / backtrack(0) / return result. subsets([1, 2, 3]) returns 8 lists, the right count. So what is wrong with them? Comment, then swipe.

**Slide 2.** Hint. The same code, with line 5 highlighted. Every subset is appended. How many different lists are in result?

**Slide 3.** The smallest case: subsets([1, 2]). Returns [[], [], [], []]. It should be [[], [1], [1, 2], [2]].

**Slide 4.** The fix. One line changes. result.append(path) becomes result.append(path[:]). JavaScript, same bug: result.push(path); becomes result.push([...path]);.

**Slide 5.** Why. result.append(path) stores the same list object every time. The backtracking pops it back to empty, so every entry ends up empty. Append a copy. From the course: Subsets, in Recursion & Backtracking.
