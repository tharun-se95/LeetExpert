## Caption

Two pointers on an array that isn't sorted. It still works, and the reason is the part interviewers push on.

Pick two lines. The water they hold is the distance between them times the shorter line's height. Find the most.

Every pair of 1,000 lines is 499,500 containers. Start with the widest container instead and move the shorter wall inward: 999 containers measured, same answer.

The rule is easy to guess and hard to prove. Here is the proof: keep the shorter wall and narrow, and the width shrinks while the height is still capped by that wall. It can never win. So one measurement speaks for every container that wall could form, and the wall is discarded.

The input isn't sorted, and sorting would destroy the widths. What makes the elimination work this time is the width shrinking with every move.

Could you have proved it in an interview? 👇

## Alt text (per slide)

**Slide 1.** Cover. Two Pointers. Unsorted input. Two pointers anyway. Container With Most Water, and why moving the shorter wall is safe.

**Slide 2.** The problem. Two lines, the most water Area is the distance between two lines times the *shorter* line's height. Python code: def brute_area(height): / best = 0 / for i in range(len(height)): / for j in range(i + 1, len(height)): / area = (j - i) * min(height[i], height[j]) / best = max(best, area) / return best. 1,000 lines, every pair: 499,500 containers.

**Slide 3.** The rule. Start widest. Move the shorter wall. Python code: def max_area(height: list[int]) -> int: / left, right = 0, len(height) - 1 / best = 0 / while left < right: / width = right - left / if height[left] <= height[right]: / best = max(best, width * height[left]) / left += 1 / else: / best = max(best, width * height[right]) / right -= 1 / return best.

**Slide 4.** Why it's safe. The shorter wall is finished Keep the shorter wall and narrow: the width shrinks, and the height is still capped by that wall. It can never win. [1,8,6,2,5,4,8,3,7]: lines 0 and 8, the widest: area 8. Best of every container that uses line 0: area 8.

**Slide 5.** Count it. Same answer, fewer containers The example, every pair: 36 containers → 49. The example, shorter wall: 8 containers → 49. 1,000 lines, every pair: 499,500 containers. 1,000 lines, shorter wall: 999 containers.

**Slide 6.** The point. Not sorted. Still works. Sorting would destroy the widths, so sortedness can't be the reason. The width shrinks with every move, so the only hope of improvement is a taller minimum, and the shorter wall is the one holding it down. That is what lets *one measurement speak for a whole family*.
